# Pehra

Pehra (पहरा, "guard") turns the free weather forecast into WBGT work-rest plans for India's outdoor workers and families, in Hindi, on WhatsApp, with Hindi phone calls for alerts. For sites with no smartphone there is a ₹600 Site Box on AWS IoT Core with a live 3D twin

- `ihcommon/`
