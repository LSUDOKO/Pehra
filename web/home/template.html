Why we built this

On 16 April 2023, people died of heatstroke at an open-air event in Kharghar, Navi Mumbai. There was no official heatwave warning that day.

India's alerts that trigger action use temperature. Humidity, sun and wind don't count. WBGT, the measure used by OSHA, NIOSH and many armies, counts all four.

No app. Really.

Tools do the maths. The AI just talks.

Compute once

Three times a day the forecast becomes WBGT for every city and 0.25° tile, cached on S3. Every user is a lookup, so a million sites cost the same as one.

Plan honestly

NIOSH limits, project rest bands and a +1 °C margin. Every number comes from code. The AI writes one sentence, and a number check blocks anything it invents.

Never loosen

Cedar policies, not prompts: the AI can make a plan stricter, never looser. Only the supervisor can loosen it, with a written reason. Each day's record is hash-chained in S3 Object Lock.
